# mnist-cnn-autoencoder
TensorFlow/Kerasを使用してMNISTデータセットで構築した深層学習モデル
Deep learning models built with TensorFlow/Keras using the MNIST dataset.

## Contents
- **Autoencoder**: Compresses and reconstructs handwritten digit images
   **オートエンコーダ**: 手書き数字画像の圧縮・復元
  
- **CNN Classifier**: Classifies handwritten digits (0-9)
 **CNN分類器**: 手書き数字（0〜9）の分類
  
## Technologies
Python / TensorFlow / Keras / NumPy / Matplotlib
